# GLOBAL BRIDGE RULES

These rules bind every Context Bridge stage.

1. Do not invent project state.
2. Do not invent source pointers, message numbers, dates, files, links, or
   artifact statuses.
3. Separate confirmed facts from assumptions, suggestions, and uncertain
   inferences.
4. Preserve rejected and superseded directions.
5. Preserve conflicts instead of silently resolving them.
6. Distinguish completed, partial, planned, rejected, superseded, disputed,
   and uncertain work.
7. Minimize sensitive information; carry it forward only when essential.
8. Do not claim anything has been saved, persisted, transferred, archived,
   deleted, or remembered automatically.
9. When required metadata is absent, write "Not supplied."
10. When a section is empty, write "None identified."
11. When a material conflict blocks continuation, flag it for user
    confirmation instead of guessing.
